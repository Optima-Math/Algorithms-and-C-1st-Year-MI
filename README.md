# 💻 تمارين الخوارزميات ولغة C - سنة أولى MI 🚀

أهلاً بك في مستودعي الخاص! يحتوي هذا المستودع على حلول التمارين، السلاسل (TDs)، والنشاطات التطبيقية (TPs) الخاصة بمقياس الخوارزميات والبرمجة (Algorithms & C Language) للسنة الأولى في ميدان الرياضيات والإعلام الآلي (MI).

---

## 📌 محتويات المستودع
يتم تقسيم الملفات بشكل منظم لمساعدتك على المراجعة والفهم:
* 📐 الخوارزميات (Algorithms): كتابة وحل المسائل البرمجية باللغة الزائفة (Pseudo-code) لفهم المنطق البرمجي.
* ⚡ لغة البرمجة سي (C Language): ترجمة الخوارزميات إلى أكواد C حقيقية وقابلة للتشغيل (.c).

---

## 📂 هيكلة المشاريع والملفات
ستجد في هذا المستودع ملفات تحضيرية وحلول مقسمة حسب السداسي:
* السداسي الأول (S1): التركيز على الأساسيات (Variables, Conditions, Loops, Arrays).
* السداسي الثاني (S2): الغوص في المفاهيم المتقدمة (Functions, Pointers, Structures, Files).

---

## 🛠️ متطلبات التشغيل (Prerequisites)
لتشغيل ملفات لغة C المتواجدة هنا على جهازك، ستحتاج إلى:
1. مثبت بيئة برمجية مثل Code::Blocks أو VS Code.
2. مترجم أكواد لغة سي مثل GCC compiler.
