# 💻 Algorithms & C Programming - 1st Year MI 🚀

Welcome to my repository! This repository contains solutions to exercises, tutorials (TDs), and practical lab sessions (TPs) for the Algorithms and Programming module, tailored for first-year students in the field of Mathematics and Computer Science (MI).

---

## 📌 Repository Contents
The files are organized into logical sections to make reviewing and learning straightforward:
* 📐 Algorithms: Problem-solving and logic building using Pseudo-code.
* ⚡ C Language: Translating algorithmic logic into real, executable C source code (.c).

---

## 📂 Project & Folder Structure
Here you will find preparatory files and solutions structured by semester:
* Semester 1 (S1): Focuses on the fundamentals (Variables, Conditions, Loops, and Arrays).
* Semester 2 (S2): Dives into advanced concepts (Functions, Pointers, Structures, and File Handling).

---

## 🛠️ Prerequisites
To run the C programs available in this repository on your machine, you will need:
1. An IDE or Text Editor such as Code::Blocks or VS Code.
2. A C language compiler like GCC compiler.

---

## ✍️ How to Use & Contribute
* Feel free to browse through the code files directly.
* You can Clone or Download the repository to test and modify the code locally on your computer.

*Best of luck to all Computer Science and Mathematics students! 🎓*
